## Overview

A four-month freelance engagement building Vertex Era's radio streaming app while still at Neoxero. The brief: a fast, mobile-first listening experience that didn't drop audio when the user navigated between pages.

## My role

Sole front-end developer for the engagement. Worked directly with the founder on UX, picked the stack, shipped to production.

## Approach

- Built the player as a top-level component that persisted across route changes, so audio wouldn't restart on navigation
- Used a global audio context so any page could control playback without prop-drilling
- Designed the now-playing UI to work just as well at 320px wide as on a desktop browser
- Lazy-loaded the station list and used a virtualized list once the catalog passed a hundred entries
